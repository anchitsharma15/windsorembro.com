# Windsor Embro

Responsive embroidery website for windsorembro.com, with an Apple-inspired white and cool-grey theme, system typography, blue calls to action and a custom woven-W logo. Uses the existing Windsor Embro product and brand artwork.

## Preview

Run `python3 -m http.server 8765` from this directory, then open http://localhost:8765. There is no build step or dependency installation.

## Features

- Responsive hero, craft story, collection, experience, project planner and FAQs.
- Collection filters and accessible native modal piece previews.
- Piece and project links preselect the relevant planner fields.
- Browser-local brief generation, copying and plain-text download.
- Keyboard focus states, native form validation and reduced-motion support.

## Content and integrations

The collection is in development. Product images are presented as design inspiration. No prices, testimonials or shipping promises are asserted. The project planner does not submit inquiries or create orders. Connect a verified business contact destination before replacing the copy/download flow with an inquiry submission. `CNAME` retains the existing domain.

## Validation

JavaScript syntax checked with `node --check script.js`. Browser checks cover mobile layout, category filtering, modal details, selected piece transfer and project brief generation. Verify final hosting deployment separately.
